# Slingy Square
## Overview
Slingy Square is a platformer game where you play as a square and try to climb up the level to reach the end in the shortest time possible by slinging yourself from platform to platform. I was inspired to make this game after playing [Slingy Square](https://scratch.mit.edu/projects/561882456) on Scratch, although I have recreated it using Pygame.

## Usage Instructions

**Download for Windows**

Download the main.exe file from my releases [here](https://github.com/shanhzagn/slingy-square/releases/tag/v1.0) and run it to start playing!

**Game Instructions and Controls**

To fling yourself, simply hover your cursor over the square and drag using left click in the opposite direction where you want to get launched. For example, to launch yourself up, drag your cursor down and then release left click. You get 2 slings before you have to recharge, which you can do by standing on the ground or on a platform. Also, if you launch yourself sideways off a platform and slide off, you still get 2 slings after you fall. This mechanic is very important for navigating some parts of the level.

There is also a timer at the top of the screen. You can press the R key on your keyboard to reset this timer, but you will also be teleported back to the start of the level. You beat the game when you touch the orange box, and the timer will be stopped, revealing your final time. My best time is 45.017 seconds. Do you think you can beat it?
